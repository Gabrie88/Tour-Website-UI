# Jimora Africa Adventures - Tour Website UI\n\nModern, responsive tour website built with Next.js, TypeScript, and Tailwind CSS.\n\n## 🌍 Features\n\n- **Responsive Design** - Works beautifully on desktop, tablet, and mobile\n- **Contact Form** - Integrated contact form with email notifications\n- **Weather Dashboard** - Real-time weather information for destinations\n- **Modern UI** - Built with Tailwind CSS and shadcn/ui components\n- **TypeScript** - Full TypeScript support for type safety\n- **API Routes** - Next.js API routes for server-side functionality\n- **Email Service** - Nodemailer integration for sending emails\n\n## 📋 Quick Start\n\n### Prerequisites\n- Node.js 18+ or higher\n- pnpm (recommended) or npm\n\n### Installation\n\n```bash\n# Install dependencies\npnpm install\n\n# Create environment file\ncp .env.local.example .env.local\n```\n\n### Environment Variables\n\nUpdate `.env.local` with your SMTP configuration:\n\n```env\n# Email Configuration\nSMTP_HOST=smtp.gmail.com\nSMTP_PORT=587\nSMTP_USER=your_email@gmail.com\nSMTP_PASSWORD=your_app_password\nSMTP_FROM_EMAIL=info@jimoraafrica.co.ke\n\n# Public Configuration\nNEXT_PUBLIC_CONTACT_EMAIL=info@jimoraafrica.co.ke\nNEXT_PUBLIC_BUSINESS_NAME=Jimora Africa Adventures\nNEXT_PUBLIC_PHONE_1=+254 711 734 900\nNEXT_PUBLIC_PHONE_2=+254 716 814 666\nNEXT_PUBLIC_LOCATION=Mombasa, Nairobi & East Africa, Kenya\n\n# Weather API (Optional)\nNEXT_PUBLIC_OPENWEATHER_API_KEY=your_openweather_api_key\n```\n\n### Development\n\n```bash\n# Start development server\npnpm dev\n\n# Open http://localhost:3000\n```\n\n### Build for Production\n\n```bash\npnpm build\npnpm start\n```\n\n## 📁 Project Structure\n\n```\n.\n├── app/\n│   ├── api/\n│   │   └── contact/\n│   │       └── route.ts           # Contact form API endpoint\n│   ├── contact/\n│   │   └── page.tsx               # Contact page\n│   └── layout.tsx                 # Root layout\n├── components/\n│   ├── contact/\n│   │   ├── ContactForm.tsx        # Contact form component\n│   │   └── ...\n│   └── weather/\n│       ├── WeatherDashboard.tsx   # Weather dashboard\n│       └── ...\n├── lib/\n│   ├── config.ts                  # Business configuration\n│   ├── email.ts                   # Email service (Nodemailer)\n│   ├── weather-api.ts             # Weather API utilities\n│   └── ...\n├── scripts/\n│   └── test-email.ts              # Email testing utility\n└── ...\n```\n\n## 📧 Contact Form\n\nThe contact form is fully integrated with email notifications:\n\n- **User Input**: Beautiful form with validation\n- **Server Validation**: Form data validation on API route\n- **Email Sending**: Nodemailer sends confirmation emails\n- **Notifications**: Success/error messages for user feedback\n\n### Using the Contact Form\n\n1. Navigate to `/contact` page\n2. Fill out the form with your details\n3. Submit - email will be sent to the business email\n4. User receives a confirmation email\n\n## 🌤️ Weather Dashboard\n\nReal-time weather information for tour destinations:\n\n- Current weather conditions\n- 5-day forecast\n- Wind, humidity, and pressure data\n- Search history\n- Responsive weather icons\n\n## 🚀 Deployment\n\nDeployed on [Render](https://render.com) with automatic redeployment on GitHub push.\n\n### Render Configuration\n\nSee `render.yaml` for deployment configuration:\n\n```yaml\nservices:\n  - type: web\n    name: jimora-africa-adventures\n    env: node\n    buildCommand: pnpm install && pnpm run build\n    startCommand: pnpm run start\n```\n\n### Setting Up on Render\n\n1. Connect your GitHub repository to Render\n2. Add environment variables in Render dashboard\n3. Render will automatically deploy on push\n\n## 📚 Technologies Used\n\n- **Next.js 16** - React framework\n- **TypeScript** - Type safety\n- **Tailwind CSS** - Styling\n- **Shadcn/ui** - UI components\n- **Nodemailer** - Email service\n- **Lucide React** - Icons\n- **OpenWeather API** - Weather data\n\n## 🔒 Security\n\n- Environment variables for sensitive data\n- SMTP authentication\n- Form validation (client & server)\n- CSRF protection with Next.js\n\n## 📞 Contact Information\n\n- **Email**: info@jimoraafrica.co.ke\n- **Phone**: +254 711 734 900 / +254 716 814 666\n- **Location**: Mombasa, Nairobi & East Africa, Kenya\n\n## 📝 License\n\nPrivate project for Jimora Africa Adventures\n\n## 🤝 Support\n\nFor issues or questions, please contact the development team.\n\n---\n\n**Built with ❤️ for Jimora Africa Adventures**\n
