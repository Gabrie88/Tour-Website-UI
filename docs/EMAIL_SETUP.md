# Email Configuration Guide\n\nThis guide explains how to set up email sending for the contact form.\n\n## Overview\n\nThe contact form uses **Nodemailer** to send emails. When a user submits the form:\n\n1. Form data is validated on the client\n2. Data is sent to the API endpoint (`/api/contact`)\n3. Server-side validation occurs\n4. Email is sent to the business using SMTP\n5. Confirmation email is sent to the user\n\n## SMTP Configuration\n\nYou need SMTP credentials to send emails. Here are popular options:\n\n### Option 1: Gmail (Recommended for Small Projects)\n\n1. **Enable 2-Factor Authentication**:\n   - Go to [Google Account Security](https://myaccount.google.com/security)\n   - Enable 2-Step Verification\n\n2. **Create App Password**:\n   - Go to [App Passwords](https://myaccount.google.com/apppasswords)\n   - Select \"Mail\" and \"Windows Computer\"\n   - Google will generate a 16-character password\n\n3. **Use These Credentials**:\n   ```\n   SMTP_HOST=smtp.gmail.com\n   SMTP_PORT=587\n   SMTP_USER=your_email@gmail.com\n   SMTP_PASSWORD=16_character_app_password\n   ```\n\n### Option 2: SendGrid (Production-Ready)\n\n1. Create a [SendGrid account](https://sendgrid.com)\n2. Get API key from Settings → API Keys\n3. Use credentials:\n   ```\n   SMTP_HOST=smtp.sendgrid.net\n   SMTP_PORT=587\n   SMTP_USER=apikey\n   SMTP_PASSWORD=your_sendgrid_api_key\n   ```\n\n### Option 3: Mailgun\n\n1. Create a [Mailgun account](https://mailgun.com)\n2. Get SMTP credentials from domain settings\n3. Use credentials provided in dashboard\n\n### Option 4: Custom SMTP Server\n\nIf you have your own SMTP server, use its credentials.\n\n## Environment Variables\n\nAdd these to your Render dashboard or `.env.local`:\n\n```env\n# Required for Email\nSMTP_HOST=smtp.gmail.com\nSMTP_PORT=587\nSMTP_USER=your_email@gmail.com\nSMTP_PASSWORD=your_app_password\nSMTP_FROM_EMAIL=info@jimoraafrica.co.ke\n\n# Business Information\nNEXT_PUBLIC_CONTACT_EMAIL=info@jimoraafrica.co.ke\nNEXT_PUBLIC_BUSINESS_NAME=Jimora Africa Adventures\nNEXT_PUBLIC_PHONE_1=+254 711 734 900\nNEXT_PUBLIC_PHONE_2=+254 716 814 666\nNEXT_PUBLIC_LOCATION=Mombasa, Nairobi & East Africa, Kenya\n```\n\n## Setting Up on Render\n\n1. **Go to Render Dashboard**\n2. **Select your service** (jimora-africa-adventures)\n3. **Go to Environment** tab\n4. **Add each variable** with its value\n5. **Save** - Render will redeploy with new environment\n\n## Testing Locally\n\n### Create .env.local\n\n```bash\ncp .env.local.example .env.local\n```\n\n### Edit .env.local\n\nAdd your SMTP credentials to the file.\n\n### Run Development Server\n\n```bash\npnpm dev\n```\n\n### Test the Contact Form\n\n1. Open http://localhost:3000/contact\n2. Fill out the form\n3. Submit\n4. Check if emails are received\n\n## Troubleshooting\n\n### \"Invalid login credentials\"\n\n- Verify SMTP_USER and SMTP_PASSWORD\n- For Gmail: Use app-specific password, not regular password\n- Check that 2FA is enabled on Gmail\n\n### \"SMTP host not found\"\n\n- Verify SMTP_HOST spelling\n- Check internet connection\n- Ensure port is correct (usually 587 or 465)\n\n### \"Cannot find module 'nodemailer'\"\n\n- Run `pnpm install`\n- Ensure package.json has nodemailer dependency\n\n### Email not being sent\n\n- Check Render logs for errors\n- Verify all environment variables are set\n- Test with correct email format\n- Check spam/junk folder\n\n## Email Templates\n\nEmails are sent in plain HTML format. To customize:\n\n1. Edit `lib/email.ts`\n2. Modify the HTML content in `sendMail()` calls\n3. Redeploy\n\n## Security Notes\n\n- Never commit `.env.local` to GitHub\n- Store sensitive passwords in environment variables only\n- Use app-specific passwords (not account password)\n- Enable 2FA for email accounts\n- Rotate app passwords periodically\n\n## Next Steps\n\n1. ✅ Set up SMTP credentials\n2. ✅ Add environment variables to Render\n3. ✅ Deploy changes\n4. ✅ Test contact form\n5. ✅ Monitor email delivery\n\n---\n\n**Questions?** Check the logs in Render dashboard or contact your administrator.\n
